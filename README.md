# sunflower. FLOW

**一个跑在自己电脑上的 AI 社交机器人。**

接 QQ / 微信 / 抖音 / B站，被 @ 或被点名时按人设回话；能画图、能发语音、记得住聊过什么。
所有数据都在本机，模型走你自己的通道，不经过任何第三方服务器。

## 安装

1. 下载上面的 `SunflowerFlow-Setup-20261102.exe`
2. 双击运行 —— 中文安装向导，**可以改安装盘符**
3. 勾选桌面快捷方式（默认已勾）
4. 装完双击桌面「Sunflower Flow」图标

首次启动会自动生成配置文件与随机网关口令，不需要手工配置。

**还需要一步**：装 Python 依赖（控制台完成页有「查看首次部署指引」，会打开说明文档，三步走）。

安装包可在 Release 页面直接下载：**[Releases](https://github.com/beizheguangdexiangrikui/SunflowerFlow/releases)**

## 常见问题

**Q：装完打开，看到的是别人机器上的数据？**

不会。每个安装目录的数据完全独立，人格、配置、记忆都在自己的 `data/` 下。

**Q：需要自己配模型吗？**

需要。控制台「模型管理」页接入你的模型通道（支持 OpenAI 兼容接口），或者用本机模型桥。

**Q：它会不会在群里乱说话？**

不会。默认「智能判断」：被 @、被点名、被回复、命中关键词才回；也可以设成「只回 @ 与点名」或「完全静音」。
「功能策略」页里还有一组「主动行为」，默认全关——不主动凑热闹、不冷场插话。

**Q：数据会上传吗？**

不会。记忆、人格、表情库都在本机 `data/` 目录，卸载时保留人格与配置、清掉日志缓存。

## 卸载

控制面板 → 程序 → 「Sunflower Flow」→ 卸载。

会清掉日志与缓存，**保留人格与配置**（重装后继续用）。
